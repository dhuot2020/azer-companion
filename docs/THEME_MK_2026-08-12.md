# Theme Azer Companion - MKProdPrioTC

## Palette officielle

```css
:root {
  --bg-dark: #002236;
  --text-light: #f5f5f5;
  --accent-green: #64a03b;
  --accent-red: #ff5555;
  --accent-orange: #f5b642;
  --font-primary: "Orbitron", sans-serif;
}
```

Les seules couleurs decoratives complementaires autorisees sont celles du cadre metallique : `#666666`, `#aaaaaa`, `#ffffff`.

Le vert, le rouge et l'orange servent a communiquer un etat ou une information. Les couleurs de classe/faction provenant dynamiquement des donnees WoW peuvent rester semantiques, mais ne deviennent pas des couleurs generales de l'interface.
