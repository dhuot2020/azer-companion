- Une seule typographie globale : **Aboreto** via Google Fonts.
- La typographie est centralisee avec `--font-primary` dans `public/css/base/base.css`.
- Aucun `!important` dans les feuilles de style.
- `public/css/app.css` redevient un point d'entree lisible : base, structure, pages, composants, responsive, theme.
- Les anciens fichiers d'override non utilises ou historiques ont ete retires.
- Les profils temporaires Edge et la copie de revue `azer_review` ont ete retires du projet distribuable.
- Les images de travail clairement non referencees ont ete retirees.
- Le code serveur, les moteurs ASE, la synchronisation, le Collector, la logique Battle.net et les donnees de jeu ont ete conserves.

## Regle de maintenance UI

Les nouvelles modifications visuelles doivent etre faites dans le fichier semantique correspondant (base, layout, page ou composant), et non sous forme d'un nouveau fichier de patch. `AZTheme.css` reste la couche visuelle partagee chargee en dernier tant que sa decomposition n'est pas terminee.
