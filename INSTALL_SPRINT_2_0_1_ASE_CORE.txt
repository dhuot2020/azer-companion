Installation :
1. Fermer Azer Companion.
2. Copier le contenu du patch a la racine du projet.
3. Accepter le remplacement des fichiers.
4. Executer npm start comme d'habitude.
5. Ouvrir /api/ase/status pour verifier le moteur.
6. Synchroniser Battle.net et verifier /api/characters.

Compatibilite :
- Le tableau characters conserve tous les champs existants.
- Chaque personnage recoit un nouveau bloc ase.
- Aucun changement requis dans l'interface actuelle.
