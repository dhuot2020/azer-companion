AZER COMPANION - BLIZZARD SYNC ENGINE - TEST 1
================================================

OBJECTIF
--------
Ce premier test ne tente pas de contourner Blizzard et ne contacte pas Wowhead.
Il ajoute une file locale sécurisée pour les portraits qui retournent 404 ou une erreur temporaire.

FICHIERS MODIFIES
-----------------
services/blizzardMediaRetry.js
routes/carnet.js
core/sync/syncManager.js

INSTALLATION
------------
1. Fermer Azer Companion.
2. Copier les trois fichiers du patch a la racine du projet.
3. Accepter le remplacement.
4. Redemarrer Azer Companion.
5. Ouvrir le Hall des heros et cliquer sur Synchroniser.

TEST
----
1. Ouvrir :
   http://localhost:3030/api/blizzard-sync/queue

2. Octaviia et les autres personnages sans media doivent apparaitre avec :
   status = waiting
   attempts = 1
   nextCheckAt = une date future

3. Une nouvelle synchronisation avant nextCheckAt ne relance pas inutilement Blizzard.

4. Pour forcer un nouvel essai immediat :
   POST http://localhost:3030/api/blizzard-sync/retry/silvermoon/Octaviia
   Puis cliquer sur Synchroniser.

FONCTIONNEMENT
--------------
- Premier echec : nouvel essai dans 5 minutes.
- Deuxieme echec : 10 minutes.
- Ensuite : 20, 40, 80 minutes, jusqu'a un maximum de 6 heures.
- Des qu'un media Blizzard retourne 200, l'entree passe a resolved.
- Le portrait Azer continue d'etre affiche pendant l'attente.

FICHIER DE FILE
---------------
data/cache/blizzard-media-retry.json

IMPORTANT
---------
Ce test ne peut pas demander officiellement une reindexation a Blizzard : aucune API publique documentee ne fournit cette action.
Il automatise uniquement les nouvelles verifications de l'API Blizzard existante.
