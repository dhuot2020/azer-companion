Azer Companion - Fiche du heros / Armurerie WoW
Version: 2026-08-07

Fichiers modifies :
- views/carnet.ejs
- public/js/app.js
- public/css/components/characters_view.css
- public/css/app.css (cache-buster CSS)

Nouveautes :
- Plein corps agrandi et centre dans la fiche.
- Portrait cree a partir de l'image haute resolution Blizzard quand disponible.
- Zoom interactif avec boutons - / +.
- Zoom avec la molette de la souris.
- Deplacement de l'image par glisser-deposer.
- Reglages memorises par personnage et par mode (Portrait / Plein corps) via localStorage.
- Bouton central de remise a zero du cadrage.
- Mise en page de l'equipement plus dense et plus proche du look WoW.

Installation :
1. Fais une sauvegarde de tes 4 fichiers actuels.
2. Copie les 4 fichiers du ZIP a leur emplacement correspondant.
3. Redemarre le serveur Node si necessaire.
4. Recharge la page avec Ctrl+F5.

Reglages par defaut dans public/js/app.js :
PROFILE_IMAGE_DEFAULT_VIEW
- full-body : zoom 1.5, x 0, y 8
- portrait : zoom 3.35, x 0, y 33

Le cadrage peut ensuite etre ajuste directement dans l'interface et sera memorise.
